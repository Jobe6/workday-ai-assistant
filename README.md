# Workday AI Assistant

prompt:
"Build a modern, responsive web application called 'AI Workplace Productivity Assistant' that helps professionals automate workplace tasks.

Design Style: Clean, modern, and professional SaaS dashboard. Use a blue and white color scheme. Include a dark mode toggle.

Layout:

A fixed sidebar on the left with navigation links for: Dashboard, Email Generator, Notes Summarizer, Task Planner, Research Assistant, and AI Chatbot.

A main content area on the right.

A top navigation bar with a user profile placeholder.

Fully responsive design for mobile and desktop.

Features to Include:

Smart Email Generator: An input area for the user's prompt, a dropdown for Tone (Formal, Friendly, Persuasive), and a 'Generate Email' button. The output should appear in an editable text box.

Meeting Notes Summarizer: A text area to paste long notes. A 'Summarize' button. The output should format into: Summary, Key Decisions, Action Items, and Deadlines.

AI Task Planner: An input for tasks/goals. The output should be a structured daily/weekly schedule prioritizing urgent tasks.

AI Research Assistant: An input for a topic. The output should provide a summary, key insights, and recommendations.

AI Chatbot: A chat interface where the user can type messages and the AI replies.

Crucial UI/UX Requirements:

All AI outputs must appear in editable text boxes.

Include a prominent 'Responsible AI Disclaimer' at the bottom of every page: 'Notice: AI-generated content may contain errors or biases. Always review and verify outputs before use.'

Add a 'Copy to Clipboard' button next to all outputs."
